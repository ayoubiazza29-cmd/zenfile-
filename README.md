# Zenfile — دليل النشر

موقع أدوات ملفات مجاني (ضغط صور، تحويل صيغ، دمج/تقسيم PDF، صور إلى PDF).
كل الأدوات تعمل بالكامل داخل متصفح الزائر (Client-side) — لا يوجد سيرفر،
لا قاعدة بيانات، ولا تكلفة استضافة تقريباً حتى مع زيارات كثيرة.

**التكلفة: $0**

---

## لماذا حساب/مستودع جديد؟

بما إن حساب Netlify الحالي وصل لحد الاستخدام المجاني لهذا الشهر، الأسهل
إنشاء **حساب Netlify جديد ببريد إلكتروني جديد** للمشروع الجديد — يعطيك
حصة مجانية كاملة من الصفر، منفصلة تماماً عن مشروع المدونة.

**ملاحظة:** حساب GitHub ما يحتاج يكون جديد، تقدر تستخدم نفس حسابك وتنشئ
فيه مستودع (Repository) جديد باسم `zenfile` مثلاً.

---

## خطوات النشر

### 1. أنشئ مستودع جديد على GitHub
1. من نفس حسابك على github.com، أنشئ **New repository** باسم `zenfile`
2. ارفع كل ملفات هذا المشروع (بنفس طريقة رفع ملفات المدونة سابقاً:
   الملفات الرئيسية عبر "Upload files"، والمجلد `tools/` يحتاج ترفع
   ملفاته عبر "Create new file" مع كتابة المسار كامل مثل `tools/compress-image.html`)

### 2. أنشئ حساب Netlify جديد
1. اذهب إلى app.netlify.com من متصفح **وضع التصفح الخفي (Incognito)**
   حتى ما يسجلك بحسابك القديم تلقائياً
2. سجّل حساب جديد ببريدك الإلكتروني الجديد
3. **Add new site → Import an existing project → GitHub**
4. اختر مستودع `zenfile` الجديد
5. اضغط **Deploy**

بعد دقيقتين، موقعك يكون شغال على رابط مجاني مثل `zenfile-xxxx.netlify.app`.

## هيكل الملفات

```
├── index.html                    الصفحة الرئيسية
├── styles.css                     نظام التصميم المشترك
├── main.js                        سكربت القائمة المتنقلة
├── netlify.toml                   إعدادات النشر
└── tools/
    ├── compress-image.html         ضغط الصور
    ├── convert-image.html          تحويل صيغة الصور
    ├── merge-pdf.html               دمج PDF
    ├── split-pdf.html                تقسيم PDF
    └── images-to-pdf.html            صور إلى PDF
```

## لا حاجة للوحة تحكم

هذا الموقع بالكامل صفحات ثابتة بدون محتوى ديناميكي (مقالات/إعدادات)،
فما فيه حاجة لأي لوحة تحكم أو قاعدة بيانات — أي تعديل مستقبلي يكون
مباشرة بتعديل ملفات HTML/CSS/JS عبر GitHub.

## خطوة لاحقة: الربح من الموقع

بعد ما يصير عندك زيارات كافية (شهر إلى شهرين من نشر محتوى/روابط):
1. سجّل بـ [Google AdSense](https://adsense.google.com)
2. ضيف كود الإعلانات في كل صفحة (قسم مخصص جاهز للإضافة لاحقاً)
3. راقب الأداء وحسّن صفحات الأدوات الأكثر بحثاً
